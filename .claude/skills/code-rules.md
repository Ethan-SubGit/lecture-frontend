이 프로젝트에서 디자인 명세를 작성하거나 코드를 생성/수정할 때는 아래 규칙을 예외 없이 지킨다.

## 핵심 규칙: 상세한 한글 주석 필수

- 새로 작성하거나 수정하는 모든 코드에는 **한글로** 상세한 주석을 단다.
- 함수/컴포넌트 상단에는 무엇을 하는 함수인지, 어떤 매개변수를 받는지, 무엇을 반환하는지 한글로 설명한다.
- 복잡한 로직, 조건 분기, 예외 처리 등 흐름이 한눈에 파악되지 않는 부분에는 왜 그렇게 처리하는지 한글 주석을 추가한다.
- 디자인 명세(design.md 등)를 작성할 때도 각 컴포넌트/레이아웃 섹션에 의도와 사용 이유를 한글로 설명하는 주석·설명을 포함한다.
- 영어 주석만 있거나 주석이 없는 코드는 미완성으로 간주한다. 기존 코드를 수정할 때도 손이 닿은 부분은 한글 주석을 보강한다.
- 변수/함수명은 기존 코드 컨벤션(영문)을 따르되, 그 의미와 역할은 반드시 한글 주석으로 설명한다.

## 적용 대상

- 신규 컴포넌트, 페이지, 유틸 함수, 훅(hook) 등 모든 코드 생성
- 기존 코드 리팩터링 및 버그 수정
- `ui-ux-designer`, `frontend-dev`, `spec-architect` 등 서브에이전트가 산출하는 코드/문서 포함
- 설정 파일이 아닌 실제 로직 코드 전반

## 체크리스트

작업을 마치기 전 아래를 확인한다.

1. 새로 추가한 함수/컴포넌트마다 역할을 설명하는 한글 주석이 있는가?
2. 복잡한 조건문·반복문·비동기 처리 등에 "왜"를 설명하는 한글 주석이 있는가?
3. 주석이 코드와 동떨어지지 않고 실제 동작을 정확히 설명하는가?
4. 디자인 산출물에도 의도를 설명하는 한글 설명이 포함되어 있는가?
